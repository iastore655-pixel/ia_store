# ia.store – موقع المتجر

## الملفات
- `index.html` : الصفحة الرئيسية
- `css/style.css` : التصميم والألوان
- `js/app.js` : المنتجات والسلة ونموذج الطلب
- `images/` : الشعار وصور الأقسام والمنتجات

## التشغيل
افتح `index.html` في المتصفح مباشرة، أو انشر المجلد كاملًا (بنفس هيكله) على GitHub Pages أو Netlify.

## ماذا تعدّل وأين (في js/app.js)
- رقم واتساب: `var WA="213671898976";`
- رابط تسجيل الطلبات (Google Apps Script): `var ORDER_URL="";`
- المنتجات: القائمة `var P=[ ... ]`
- أسعار التوصيل: ابحث عن `800:400` (800 للمنزل، 400 للمكتب) وعن `400 DA` و`800 DA` في `index.html`
- الألوان: أول `css/style.css` (متغيرات `:root`)

## البلديات
- قائمة الولايات محدّثة إلى 69 ولاية وفق التقسيم الإداري لسنة 2026.
- عند اختيار التوصيل للمنزل، تُحمّل قائمة البلديات (1,541 بلدية) من ملف بيانات عام. يلزم اتصال بالإنترنت لعرض القائمة؛ إذا تعذّر التحميل يظهر حقل إدخال يدوي حتى لا يتوقف الطلب.
- مصدر بيانات البلديات: [wadiemendja/algeria-communes-wilayas](https://github.com/wadiemendja/algeria-communes-wilayas) — MIT License.
